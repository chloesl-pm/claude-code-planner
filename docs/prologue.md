# 📖 들어가며

> 비개발자를 위한 AI 업무 자동화 실전 가이드 — Prologue

## ✏️ 이 백서를 쓰게 된 이유

기획자는 늘 경계에 서 있습니다.  
개발팀과 사업팀 사이, 요구사항과 구현 가능성 사이, 그리고 빠르게 변하는 기술과 현실적인 업무 속도 사이에서.

저는 클라우드 서비스 기획자입니다. 기획 업무를 기반으로 하되, 개발 언어를 읽고 분석할 수 있으며, API와 SDK를 직접 검증하고, 다양한 데이터베이스를 다룰 수 있습니다. 기획 검증 단계에서 개발 관점의 사고를 함께 적용해왔습니다.

그러던 중 **Claude Code**를 만났고, 제 업무 방식이 달라지기 시작했습니다.  
단순히 "AI에게 질문하는 것"을 넘어서, **MCP 연동, 자동화 툴 구축, 문서 자동 생성**까지 — 기획자의 손으로 직접 만들어낼 수 있다는 걸 경험했습니다.

이 백서는 그 경험의 기록입니다. 화려한 기술 스택을 설명하는 문서가 아니라, **"기획자가 Claude Code를 어떻게 실제 업무에 녹여냈는가"**에 대한 실전 가이드입니다.

## 👤 이 백서를 쓴 사람

| 항목 | 내용 |
| --- | --- |
| **역할** | 클라우드 서비스 기획자 (Kakao Enterprise) |
| **기술 배경** | 개발 경험 보유 / 코드 분석 가능 / 다양한 DB 운용 경험 |
| **기획 역량** | API · SDK 기획 검증, 서비스 스펙 설계, 사용자 가이드 작성 |
| **AI 활용 수준** | Claude Code CLI + MCP 다중 연동 + 자동화 툴 직접 구축 |
| **주요 연동 MCP** | Confluence, Jira, Figma, GitHub, Kakao Cloud Docs |

## 🤔 왜 Claude Code인가

기획자에게 필요한 것은 단순한 챗봇이 아닙니다. 맥락을 이해하고, 시스템과 연동되며, 반복 작업을 자동화하고, 결과물을 직접 만들어내는 도구가 필요합니다.

:::tip ✅ Claude Code가 충족한 조건
- **MCP(Model Context Protocol)** 를 통해 Confluence, Jira, Figma 등 업무 도구와 직접 연결됩니다.
- 터미널 기반 CLI로 동작하며, 코드·문서·API를 하나의 흐름에서 처리할 수 있습니다.
- 프로젝트 설정 파일(`CLAUDE.md`)과 커스텀 명령어로 팀 맞춤 어시스턴트를 만들 수 있습니다.
- 개발 지식이 있는 기획자라면, 단순 자동화를 넘어 **직접 툴을 설계하고 구축**하는 수준까지 활용할 수 있습니다.
:::

## 📚 이 백서의 구성

이 백서는 총 9개의 챕터로 구성되며, 각 챕터는 독립적으로 참고할 수 있습니다.

| 챕터 | 주제 | 핵심 내용 |
| --- | --- | --- |
| **CH.0** | 기획자에게 Claude Code가 필요한 이유 | 도입 배경, 기대 효과 |
| **CH.1** | 환경 구축 | 설치, MCP 연동 세팅 |
| **CH.2** | 반복 업무의 종말 | 자동화 대상 발굴, Before/After |
| **CH.3** | MCP Confluence 연동 | 회의록·기획서·스펙 문서 자동화 |
| **CH.4** | MCP Jira 연동 | 티켓 생성·관리 자동화 |
| **CH.5** | MCP Figma 연동 | 기획 화면 시안 제작 |
| **CH.6** | 카카오클라우드 사용자 가이드 작성 | KC-docs 기반 초안 자동 생성 |
| **CH.7** | API 자동화 테스트 툴 구축 | Swagger JSON → 자동화 테스트 툴 |
| **CH.8** | 경쟁사·레퍼런스 분석 자동화 | 리서치 → 보고서 자동 생성 |
| **CH.9** | 나만의 기획 어시스턴트 만들기 | CLAUDE.md + 커스텀 명령어 총정리 |

## 🙋 이 백서가 도움이 될 분

- 📌 Claude Code를 업무에 적용하고 싶은 **IT 기획자 / PM**
- 📌 개발 지식은 있지만 AI 툴 활용을 막 시작하는 **테크 기획자**
- 📌 Confluence, Jira, Figma를 매일 쓰면서 **반복 작업에 지친 실무자**
- 📌 AI 기반 업무 자동화를 팀에 도입하고 싶은 **리드/매니저**

> 💡 이 백서는 완성된 정답이 아니라, **현재 진행 중인 실험의 기록**입니다.  
> 각 챕터는 실제 업무에서 사용한 방법과 결과를 바탕으로 작성되었으며, 함께 발전시켜 나갈 수 있습니다.
