# CHAPTER 2. 반복 업무의 종말

> 매일 낭비하던 시간을 AI가 돌려줬다

## 🕐 Claude Code 도입 전, 나의 하루 업무 루틴

기획자의 하루는 겉으로는 바빠 보이지만, 실제로 얼마나 많은 시간이 **"진짜 기획"**에 쓰이고 있을까요? 도입 전 하루를 솔직하게 되돌아봤습니다.

| 시간대 | 업무 | 실제로 걸린 시간 |
| --- | --- | --- |
| 오전 09~10시 | 전날 회의록 정리 및 Confluence 업로드 | 약 40분 |
| 오전 10~11시 | Jira 티켓 상태 확인 및 코멘트 업데이트 | 약 30분 |
| 오후 02~04시 | 경쟁사 리서치 자료 수집 및 기획서/보고서 초안 | 약 2시간 |
| 오후 04~05시 | API 스펙 변경에 따른 문서 수정 및 공유 | 약 1시간 |
| 수시 | Google Chat 문의 대응, 문서 링크 찾기 | 약 1시간+ |

:::warning 😓 하루 8시간 중 진짜 기획에 쓴 시간은?
위 항목들만 합쳐도 하루 **5시간 이상**이 반복·행정 업무에 소요됩니다.  
실제 서비스 방향을 고민하고, 사용자 경험을 설계하는 "진짜 기획"에 쓸 수 있는 시간은 **하루 2~3시간**에 불과했습니다.
:::

## 🔍 자동화 대상 업무 발굴 방법

Claude Code 도입에 앞서, 어떤 업무부터 자동화할지 기준을 세웠습니다. 아래 3가지 조건을 모두 충족하는 업무를 우선 대상으로 삼았습니다.

| 기준 | 설명 | 자동화 적합도 |
| --- | --- | --- |
| **① 반복 빈도가 높다** | 매일 또는 매주 동일한 패턴으로 발생하는 업무 | ⭐⭐⭐ |
| **② 판단보다 실행이 많다** | 창의적 사고보다 정해진 형식에 맞춰 옮기는 작업 | ⭐⭐⭐ |
| **③ 실수가 잦다** | 복붙·수동 입력 과정에서 오타나 누락이 자주 발생 | ⭐⭐ |

### 내 업무 중 자동화 대상으로 선정한 항목

| 업무 | 자동화 방법 | 관련 챕터 |
| --- | --- | --- |
| 회의록 작성 및 Confluence 업로드 | MCP Confluence 연동으로 초안 생성 및 자동 업로드 | CH.3 |
| Jira 티켓 생성·상태 업데이트 | MCP Jira 연동으로 명령어 한 줄 처리 | CH.4 |
| 경쟁사·레퍼런스 분석 보고서 | 웹 리서치 → 구조화 → 문서 출력 자동화 | CH.8 |
| API 스펙 검증 | Swagger JSON 기반 자동화 테스트 툴 구축 | CH.7 |
| 사용자 가이드 문서 초안 | KC-docs clone 후 Claude Code로 초안 작성 | CH.6 |

## 📊 도입 전후 업무 시간 비교

Claude Code 도입 후 약 한 달간 주요 업무별 소요 시간을 측정했습니다.

| 업무 | 도입 전 | 도입 후 | 단축 효과 |
| --- | --- | --- | --- |
| 회의록 정리 및 업로드 | 약 40분 | 약 10분 | **75% ↓** |
| Jira 티켓 생성·관리 | 약 30분 | 약 5분 | **83% ↓** |
| 경쟁사 기획서/보고서 초안 | 약 2시간 | 약 30분 | **75% ↓** |
| API 스펙 검증 | 약 1시간 | 약 10분 | **83% ↓** |
| 사용자 가이드 초안 | 약 3시간 | 약 40분 | **78% ↓** |

:::tip 📈 수치로 본 변화
- 반복 업무 소요 시간: 하루 평균 **5시간 → 1.5시간**으로 단축
- 확보된 여유 시간: 하루 **약 3~4시간** — 실제 기획·분석에 재투자
- 문서 품질: 형식 오류·누락 빈도 **현저히 감소**
- 심리적 변화: 반복 작업 스트레스 감소, 기획 본연의 업무 집중도 향상
:::

## 💡 자동화가 어려운 업무도 있다

모든 업무가 자동화 대상은 아닙니다. Claude Code 도입 과정에서 **"이건 AI가 대신할 수 없다"**는 것도 명확해졌습니다.

| 자동화 하기 어려운 업무 | 이유 |
| --- | --- |
| 이해관계자 설득 및 협의 | 맥락과 관계 기반의 판단이 필요 |
| 서비스 방향성 결정 | 비즈니스 목표와 사용자 니즈의 균형 조율 |
| 신규 기능의 UX 설계 | 창의적 발상과 사용자 공감 능력 필요 |
| 팀 내 갈등 조율 | 감성적 판단과 상황 대응 능력 필요 |

Claude Code는 기획자를 대체하는 도구가 아닙니다. **반복 실행을 대신 맡아주는 동안, 기획자는 더 본질적인 일에 집중할 수 있게 됩니다.** 다음 챕터부터는 각 자동화 사례를 실전 워크플로우로 상세히 다룹니다.
