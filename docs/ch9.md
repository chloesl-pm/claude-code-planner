# CHAPTER 9. 제안서 작성

> 수치 분석부터 대시보드 제안서까지 — AI가 만든 초안을 기획자의 언어로 다듬는 과정.

## 배경 — 왜 제안서에 AI를 썼나

판가 인상 전략을 수립해야 했습니다. 국내외 CSP의 동일 서비스·상품 가격을 조사하고, 자사 상품의 현재 가격 위치와 인상 전략을 수치로 정리해서 C레벨과 대표에게 보고해야 하는 상황이었습니다.

비교 대상이 수십 개의 SKU에 달했고, CSP마다 가격 구조도 달라 수동으로 정리하면 수치 계산과 차트화에만 하루 이상이 소요될 작업이었습니다.

## 준비 단계 — 데이터 구조 설계

Claude Code에 넘기기 전, 기획자가 직접 준비한 것들입니다.

| 항목 | 내용 |
|---|---|
| **조사 범위 정의** | 국내 CSP, 해외 CSP 대상 / 동일 서비스·상품 카테고리 기준 통일 |
| **엑셀 구조 설계** | SKU별 AS-IS 가격, 경쟁사 가격, 비교 기준 컬럼 직접 정의 |
| **수집 기준 수립** | 공정 비교를 위한 스펙 기준 통일 (vCPU, 메모리, 스토리지 단위 등) |

> 데이터 수집과 기준 설계는 기획자가 직접 했습니다. Claude Code는 이 데이터를 받아 분석·시각화하는 역할입니다.

## Claude Code 활용 — 분석 및 시각화

엑셀 파일을 Claude Code에 넘기고 아래 작업을 순서대로 요청했습니다.

| 순서 | 작업 | 프롬프트 방향 |
|---|---|---|
| **1** | SKU 분류 및 비중 파악 | 전체 SKU 중 인상 대상 / 비대상 비율 도출 |
| **2** | 가격 포지셔닝 분석 | 자사 vs 경쟁사 가격 비교 및 격차 수치화 |
| **3** | 인상률 산출 | AS-IS 대비 TO-BE 인상률 % 자동 계산 |
| **4** | 차트·대시보드 생성 | 보고용 그래프·차트 HTML로 자동 생성 |
| **5** | 제안서 구조 초안 | C레벨 보고용 흐름으로 내용 재구성 요청 |

## 검수 — AI 결과물을 기획자의 언어로

Claude Code가 생성한 초안을 그대로 쓰지 않았습니다. 보고 대상이 C레벨과 대표인 만큼 AI 특유의 표현을 걷어내는 검수 과정이 필수였습니다.

**걷어낸 것들**

- **과도한 수식어** — "매우 중요한", "핵심적인", "효과적으로" 등 불필요한 강조 표현
- **AI식 나열** — bullet 3~5개 나열 구조 → 핵심 1~2개로 압축
- **설명 과잉** — 보는 사람이 이미 아는 배경 설명 반복
- **근거 없는 결론** — 수치 없이 "경쟁력 있는 가격입니다" 식의 막연한 판단
- **용어 불일치** — 같은 개념을 다르게 표현한 경우 자사 표현으로 통일

| 검수 포인트 | 기준 |
|---|---|
| **톤** | 사실 기반, 판단은 수치로 뒷받침 |
| **밀도** | C레벨 보고: 1페이지당 핵심 메시지 1개 |
| **용어** | 자사 내부 표현 기준으로 통일 |
| **차트 레이블** | 범례·단위·기준 명시 여부 확인 |
| **결론 문장** | 수치 없는 결론 문장은 전부 재작성 |

## AI가 한 것 vs 기획자가 한 것

| 구분 | Claude Code | 기획자 (직접) |
|---|---|---|
| **데이터** | 엑셀 수치 파싱 및 계산 | 조사 범위 정의, 데이터 수집, 기준 설계 |
| **분석** | 인상률 산출, 경쟁사 비교 수치화 | 전략 방향 결정, 근거 판단 |
| **시각화** | 차트·대시보드 자동 생성 | 차트 유형 선택, 구성 방향 지시 |
| **내용** | 구조 초안, 문장 초안 | 전략 내용 채우기, 검수·편집, 최종 확정 |
| **제안서** | 보고 흐름 초안 제안 | 자사 스타일에 맞게 재구성, 핵심 압축 |

## Before / After

| 항목 | Before | After |
|---|---|---|
| 수치 계산 및 인상률 산출 | 엑셀 수식 직접 작성 (~2시간) | **프롬프트 요청 후 즉시 (~10분)** |
| 차트·대시보드 생성 | 차트 툴 직접 조작 (~1~2시간) | **HTML 대시보드 자동 생성 (~15분)** |
| 제안서 초안 구성 | 빈 슬라이드부터 직접 작성 (~3시간) | **구조 초안 생성 + 검수·편집 (~1시간)** |
| **전체 소요 시간** | 약 1~2일 | **약 반나절** |

> - Claude Code는 수치 계산과 시각화를 빠르게 처리합니다. 전략 판단과 내용은 기획자의 몫입니다.
> - AI가 만든 초안을 검수 없이 그대로 쓰면 보고 자료가 될 수 없습니다.
> - 검수 기준을 한 번 잡아두면, 다음 제안서는 더 빠르게 완성됩니다.
