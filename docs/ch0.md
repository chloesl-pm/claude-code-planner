# CHAPTER 0. 기획자에게 Claude Code가 필요한 이유

> Claude Code가 무엇인지, 왜 기획자에게 유용한지 짧게 정리했습니다.

## 기획자의 시간은 어디서 사라지는가

회의가 끝나면 회의록 정리, 스펙이 바뀌면 문서 수정과 Jira 티켓 업데이트, API 기획이 끝나면 Postman으로 직접 검증, 경쟁사 분석이 필요하면 탭을 수십 개 열어 수동 취합 등..

이건 기획이 아니라 늘 반복되는 **작업**입니다. 실제 고민과 판단에 써야 할 시간이 반복 실행에 소모되고 있다고 생각했습니다. "Claude Code"는 이러한 반복되는 작업들을 대신 처리해줍니다.

## Claude Code란?

Anthropic이 만든 터미널 기반 AI 에이전트입니다. 질문에 답하는 챗봇이 아니라, 파일을 읽고 수정하며 외부 시스템과 연동해 실제로 실행하는 도구입니다.

| 구분 | 설명 |
|---|---|
| **실행 환경** | 터미널(CLI) 기반. 프로젝트 디렉토리 전체를 컨텍스트로 인식 |
| **MCP 연동** | Confluence, Jira, Figma, GitHub 등 외부 도구와 직접 연결 |
| **파일 처리** | 문서 생성, 수정, 코드 분석, JSON 파싱 등 결과물을 직접 만들어냄 |
| **커스터마이징** | CLAUDE.md와 Slash Commands로 팀 맞춤 워크플로우 구성 |

## 기획자가 실제로 쓸 수 있는 것들

- **문서 자동화** — 회의록·기획서·스펙 문서를 Confluence에 자동 생성·수정 (CH.3)
- **티켓 관리** — Jira 티켓 생성·조회·상태 변경을 명령어 한 줄로 (CH.4)
- **시안 제작** — Figma 컴포넌트를 참조해 기획 화면 초안 직접 제작 (CH.5)
- **기획 검증 자동화** — Harness 패턴으로 기획 검증 프로세스 자동화 (CH.7)
- **API 검증** — Swagger JSON 기반 자동화 테스트 툴 직접 구축 (CH.8)
- **가이드 문서** — GitHub clone 후 공식 문서 초안 빠르게 완성 (CH.6)

## 일반 AI 챗봇과의 차이

| 비교 항목 | 일반 AI 챗봇 | Claude Code |
|---|---|---|
| 결과물 생성 | 텍스트 답변만 | **파일·문서 직접 생성** |
| 외부 시스템 연동 | ❌ | **✅ MCP로 직접 연동** |
| 프로젝트 컨텍스트 | 대화 내용만 | **디렉토리 전체 파악** |
| 반복 작업 | 매번 수동 입력 | **커스텀 명령어로 자동화** |
