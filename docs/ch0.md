# CHAPTER 0. 기획자에게 Claude Code가 필요한 이유

> Claude Code란 무엇인지, 왜 기획자에게 유용한지를 설명합니다.

## 💬 기획자의 하루, 어디서 시간이 사라지는가

기획자의 하루는 생각보다 많은 반복으로 채워져 있습니다.

- 회의가 끝나면 회의록을 정리하고 Confluence에 올린다
- 기능 정의가 바뀌면 스펙 문서를 찾아서 수정하고, 관련 Jira 티켓도 업데이트한다
- API 기획을 완료하면 개발팀에 전달하기 전에 직접 Postman으로 검증해본다
- 경쟁사 분석이 필요하면 탭을 수십 개 열어 자료를 수동으로 취합한다

이 모든 과정은 **"기획"이 아닌 "작업"**입니다. 실제 고민과 판단에 써야 할 시간이, 반복적인 실행에 소모되고 있습니다.

Claude Code는 이 **"작업"의 상당 부분을 자동화**하고, 기획자가 본질적인 사고에 집중할 수 있도록 돕습니다.

## 🤖 Claude Code란 무엇인가

Claude Code는 Anthropic이 만든 **터미널 기반 AI 코딩 에이전트**입니다. 단순히 질문에 답하는 챗봇이 아니라, 실제 파일을 읽고 수정하며, 외부 시스템과 연동하고, 명령을 실행하는 **능동적인 작업 도구**입니다.

| 구분 | 설명 |
| --- | --- |
| **실행 환경** | 터미널(CLI) 기반으로 동작, 프로젝트 디렉토리 전체를 컨텍스트로 인식 |
| **MCP 연동** | Model Context Protocol을 통해 Confluence, Jira, Figma, GitHub 등 외부 도구와 직접 연결 |
| **파일 처리** | 문서 생성·수정, 코드 분석, JSON 파싱 등 실제 결과물을 직접 만들어냄 |
| **커스터마이징** | CLAUDE.md 설정 파일과 Slash Commands로 팀 맞춤 워크플로우 구성 가능 |

## 🙋 기획자에게 특히 유용한 이유

Claude Code는 개발자만을 위한 도구가 아닙니다. 오히려 **개발과 기획의 경계에 있는 테크 기획자**에게 가장 강력한 도구가 됩니다.

:::tip ✅ 기획자가 Claude Code로 할 수 있는 것
- 📄 **문서 자동화** — 회의록·기획서·스펙 문서를 Confluence에 자동 생성·수정
- 🎫 **티켓 관리** — Jira 티켓 생성, 조회, 상태 변경을 명령어 한 줄로 처리
- 🎨 **시안 제작** — Figma 컴포넌트를 참조해 기획 화면 초안을 직접 제작
- 🔧 **API 검증** — Swagger JSON으로 자동화 테스트 툴을 직접 구축하여 기획 검증
- 📊 **리서치 자동화** — 경쟁사·레퍼런스 분석 보고서를 빠르게 초안 생성
- 📝 **가이드 문서 작성** — GitHub에서 공식 문서를 clone해 초안을 빠르게 완성
:::

## ⚡ 일반 AI 챗봇과 무엇이 다른가

| 비교 항목 | 일반 AI 챗봇 | Claude Code |
| --- | --- | --- |
| **결과물 생성** | 텍스트 답변만 제공 | **실제 파일·문서 직접 생성** |
| **외부 시스템 연동** | ❌ 불가 | **✅ MCP로 직접 연동** |
| **프로젝트 컨텍스트** | 대화 내용만 기억 | **디렉토리 전체 파악** |
| **반복 작업 자동화** | 매번 수동 입력 필요 | **커스텀 명령어로 자동화** |
| **API 검증** | 설명만 가능 | **툴 직접 구축 및 실행** |
